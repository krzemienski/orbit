Purpose

# Scenario 06 — Configurable Review Window

Verify Orbit's review-window is configurable, not hardcoded to 3 days, by running three live SDK invocations: `--days 7`, `--since 2026-05-01`, `--from 2026-05-01 --to 2026-05-04`.

Prompt

/orbit:review-window --days 7 Audit this project.
/orbit:review-window --since 2026-05-01 Audit this project.
/orbit:review-window --from 2026-05-01 --to 2026-05-04 Audit this project.

Expected Observations

# Expected Observations

- `evidence.json` scope echoes the selected window for each invocation.
- Markdown report and dashboard state the selected window.
- `review-last-3-days` is documented as alias for `--days 3`.

Success Criteria

# Success Criteria

- Three `ResultMessage`s observed across three runs.
- Scope object echoes correct values (`days=7`, `since=2026-05-01`, `from/to=2026-05-01..2026-05-04`).
