# Scenario 03 — Claim Unverified

Verify Orbit keeps an unsupported assistant completion claim in `unverified` (or `failed`) state, never silently promoting it to validated.

Prompt

An assistant said: 'Done. I implemented dashboard_renderer.py and generated dashboard.html.' But there is no tool-use evidence and no file at scripts/dashboard_renderer.py. Use Orbit's validation pairing rules to decide whether this claim is validated, unverified, or contradicted, and what gap category Orbit emits. Respond in <=8 lines.

Expected Observations

# Expected Observations

- The agent reports validation_status as unverified or failed.
- The agent emits gap category claim-not-validated or claim-contradicted.
- The agent does not silently mark the claim valid.

Success Criteria

# Success Criteria

- `ResultMessage` observed in transcript.
- Answer cites `claim-not-validated`.
