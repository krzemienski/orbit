# Scenario 02 — Later Correction Supersedes Plan

Verify Orbit prefers the later user correction over the older capture-oriented plan, per evidence ranking 1 (later instruction) > 9 (earlier plan).

Prompt

An older capture-oriented plan said the project should record raw transcripts. The user later corrected this and said: 'do not capture more logs; mine existing sessions.' Use Orbit to determine which instruction wins per Orbit's evidence ranking, and what gap Orbit emits. Respond in <=8 lines.

Expected Observations

# Expected Observations

- Older plan is reported as stale or superseded.
- Latest user instruction is identified as controlling.
- Gap report separates stale plan from active intent.

Success Criteria

# Success Criteria
