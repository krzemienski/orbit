Purpose

# Scenario 01 — Plan Gap

Verify Orbit detects an intent (dashboard visualization) that the written plan omits, and emits an `intent-not-planned` or `plan-omission` gap with a remediation recommendation.

Prompt

Use Orbit to audit this project. The written plan mentions skills and commands, but recent sessions include a user request for first-class dashboard visualization. Determine whether the dashboard request is captured by the plan, implemented in the codebase, and validated by current artifacts. Respond in <=8 lines.

Expected Observations

# Expected Observations

- The agent reports the dashboard intent is present.
- The agent reports plan coverage as omitted (`intent-not-planned` or `plan-omission`).
- The agent suggests either implementing dashboard rendering or updating the plan.

Success Criteria

# Success Criteria

- `transcript.json` non-empty with a `ResultMessage`.
- Answer cites the plan-omission gap category.
