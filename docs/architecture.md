# Local Architecture

This is a deep map of Orbit's local codebase, derived from the actual filesystem (not from any external README assumption). It is regenerated by `sdk_orbit_all.py::architecture_discovery()` on every harness run and persisted to `reports/orbit-architecture-discovery.md`.

## Plugin root

```
/Users/nick/Desktop/orbit/
```

(or wherever the plugin root resolves: `${CLAUDE_PLUGIN_ROOT:-$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)}` per the bin wrappers)

## Surface inventory

| Surface | Path | Role |
|---|---|---|
| Manifest | `.claude-plugin/plugin.json` | Plugin contract (name, version, paths) |
| Skills | `skills/<name>/SKILL.md` | Four operational skills |
| Commands | `commands/<name>.md` | Eight slash commands |
| Hooks | `hooks/hooks.json` | Two hook events |
| Hook scripts | `scripts/hook_instruction_detector.py`, `scripts/hook_prompt_context.py` | Stdin JSON readers |
| Engine | `scripts/orbit_audit.py` | The single Python helper that does all audit work |
| Bin wrappers | `bin/orbit-audit`, `bin/orbit-dashboard`, `bin/orbit-ledger` | Thin bash shims around `orbit_audit.py` |
| Examples | `examples/sample-evidence.json`, `examples/sample-plan.md`, `examples/sample-gap-analysis.md` | Bundled fixtures |
| Tests | `tests/test_orbit_scripts.py`, `tests/fixtures/sample-session.jsonl`, `tests/fixtures/sample-plan.md`, `tests/fixtures/sample-repo/` | Smoke fixtures used by `validate_outputs.py` |
| Docs | `docs/`, `docs-html/`, `docs/diagrams/` | This documentation suite |
| SDK harness | `.orbit-sdk-harness/` | Validation runner + scenarios + reports |

## Engine internals (`scripts/orbit_audit.py`)

| Function | Role |
|---|---|
| `compute_window` | Resolve `--days`/`--since`/`--from`/`--to` to UTC `[start_dt, end_dt]` |
| `discover_sessions` | Walk `~/.claude/projects/**/*.jsonl`, mtime + project-substring filter |
| `read_jsonl` | Forgiving line-by-line JSON parse, malformed lines logged + skipped |
| `flatten` | Recursive content extraction over a fixed allowlist of keys |
| `extract_intents` / `extract_claims` / `extract_tool_evidence` | Per-role extractors |
| `extract_plan_items` | Markdown plan parser (heading + checkbox/bullet) |
| `validate_codebase` | Default safe checks: artifact_exists + claim_path_exists |
| `analyze_gaps` | Token-Jaccard + claim status → gap records |
| `make_evidence` | Glue everything into the `evidence.json` schema |
| `render_dashboard` | Build the static HTML with hero, cards, matrix, timeline, claims, gaps, uncertainty |
| `render_markdown` | Build `gap-analysis.md` with scope echo + executive summary + gap detail |
| `build_ledger` | Append durable instructions to `intent-ledger.jsonl` + write `.md` companion |

## Subcommands

```text
audit                Full pipeline. Default output: .claude/audits/latest/
build-ledger         Durable instruction ledger (--replace truncates)
compare-plan         Alias for audit with --plan accumulator
validate-claims      Re-validate from existing evidence
render-dashboard     Render dashboard from existing evidence
```

## Evidence flow

```
user instruction → plan evidence → assistant claims → tool evidence → codebase truth → gaps → dashboard + Markdown + JSON + Mermaid + CSV
```

`evidence.json` is the canonical document; everything else is a render of it.
