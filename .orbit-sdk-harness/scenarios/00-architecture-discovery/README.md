# Scenario 00 — Architecture Discovery

Deeply inspect Orbit's local codebase before validating any behavior. The harness must produce an evidence-backed architecture map that names the manifest, skills, commands, hooks, scripts, bin wrappers, dashboard renderer, evidence model, and validation surfaces it discovered — not what it assumes.

This scenario is the gate for every later scenario: if the architecture cannot be mapped from the local files, no functional validation should be trusted.
